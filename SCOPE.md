# Scope

## Included

- **Synthetic studies.** All synthetic studies reported in the paper: S1–S3, the label swap, the Qwen3 reasoning anchor, the Qwen2.5 reason-then-score ablation, and the Qwen2.5 scale ablation. Each includes its generated datasets, prompts, preregistrations (and amendments), raw judge scores, metrics, bootstrap results, figures and integrity records.
- **Post-study analyses.** The artifact-blind reference strategies and the reachability/theory audit.
- **Post-hoc manuscript analyses.** The code and outputs in `scripts/posthoc/` and `artifacts/posthoc_manuscript/`:
  - re-scoring at $L=5$;
  - the permutation null and scale-normalized tolerance;
  - MVR sensitivity to $\delta$;
  - the TR split against held-out S2 recalibration.
- **Code and environment.** The library source, the test suite, and the job scripts used to run inference.
